# Инвентаризация ИИ-агента

## 1. Паспорт проекта
Название: ИИ-Помощник по учёту расходов
Назначение: Анализ личного бюджета, поиск экономии, планирование накоплений.
Основные функции: Чат с нейросетью, поиск по базе знаний (RAG), вывод структурированных советов.
Файл запуска: `main.py`
Язык и версия Python: Python 3.15.0 (Windows)
Дата проверки: 18.11.2026

## 2. ИИ-компоненты
Модель и поставщик: GigaChat-2 сбер
API или локальная модель: Облачный API
Библиотека подключения: `gigachat` (Python)
Файл вызова модели: `main.py`
Промпты и инструменты: Системный промпт в `prompts.py`, RAG-поиск через TF-IDF.
## 3. Реестр компонентов:
 № | Компонент |     Тип    |      Назначение   | Версия | Расположение |

2.    gigachat | Библиотека | Подключение к API | 0.1.35 | venv |
3. scikit-learn| Библиотека |Векторизация (TF-IDF)| 1.5.2 | venv |
